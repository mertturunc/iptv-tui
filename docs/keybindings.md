# Key bindings

Inventory of primary keys and aliases. Update this file, `helpView`, footer hints, and README together when changing bindings.

## Main

Navigation: `up/down` (`j/k`), `pgup/pgdn`, `tab`, `left/right` (`h/l`), `g`/`G` (groups), `[`/`]` (media tabs)
Play: `enter`/`space`, `o`/`p`
Channel jump: `#` or `0-9` + `enter`
Media tabs: `1` Live, `2` Movies, `3` Series
Favorite: `f`/`F`/`*`
Filter: `/`/`ctrl+f`
EPG: `e`/`i`
Sources: `s`/`S`
Add source: `a`/`n`/`+`
Reload: `r`/`R`
Delete source (sources sheet): `d`/`D`/`delete`
Chromecast: `c`/`C`
AirPlay: `v`/`V`/`A`
Stop all: `x`/`X`
Keep mpv on quit: `m`/`K`
Help: `?`/`F1`
Quit: `q`/`Q`/`ctrl+c`

## Series

`enter` selects/opens; `backspace`/`esc` exits series.

## Forms/overlays

Toggle M3U/Xtream: `k`/`t`
Navigation: arrows (`j`/`k`)
Rescan: `r`/`R`
Cancel: `esc`
